# NTX - Open Letterhead

A blank, printable letterhead page for North Texas Elite Pool Care.

- Header matches the Chemical Balancing report: logo (left), phone graphic (center), QR code with "Visit Us Online" (right). All logos link to the main site.
- **Customer** button toggles Customer Name, Address, and Email Address fields.
- Rich text body supporting bold, italic, underline, bulleted and numbered lists, and headings.
- Footer with copyright and service-area lines.
- Print styles output a clean Letter-portrait page.

## Usage

Open `index.html` in a browser, or visit the published GitHub Pages site.
